# 📊 Merge Sort Visualizer

A beautiful, interactive web application built to visualize the classic Merge Sort algorithm in real-time. This project uses dynamic color gradients and audio feedback to make understanding the divide-and-conquer mechanism intuitive and engaging.

🔗 **Live Demo:** [Launch Visualizer](https://merge-sort-visualizer-tcli.onrender.com)

---

## Features

* **Real-Time Animation:** Watch the Merge Sort algorithm sort elements step-by-step.
* **Gradient UI:** Uses a smooth, shifting color gradient instead of standard bars for a modern look.
* **Scramble Colors:** A dedicated button to instantly randomize the array and its color spectrum.
* **Sound Effects:** Immersive audio synthesis where pitch maps directly to the values being sorted.
